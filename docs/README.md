# 每日抽卡插件文档索引

本文档目录用于约束 `astrbot_plugin_dailycarddraw` 的开发边界、目录结构与接口定义。

当前已确认方向：

- 抽卡模型：`十连/多模式`
- QQ 号数据范围：`按 QQ 全局`
- 云端存储方式：`MySQL API`
- 第一版能力：`不包含榜单功能`
