# 数据模型与云端接口

## 核心业务对象

第一版建议围绕以下对象建模：

- `UserProfile`
  - QQ 用户基础信息与累计统计
- `CardPool`
  - 卡池定义
- `CardItem`
  - 卡牌定义
- `PoolCard`
  - 卡池与卡牌关系、权重
- `DailyQuota`
  - 用户每日次数状态
- `DrawRecord`
  - 抽卡记录
- `DrawRecordItem`
  - 单次抽卡中每一张卡的明细

## 云端 API 设计

建议后端统一前缀：

```text
/api/daily-carddraw
```

## 用户接口

### `POST /api/daily-carddraw/draw`

用途：

- 发起一次抽卡

请求体建议：

```json
{
  "qq_id": "123456789",
  "group_id": "987654321",
  "pool_key": "normal_pool",
  "draw_mode": "single",
  "nickname": "用户昵称"
}
```

响应体建议：

```json
{
  "success": true,
  "message": "抽卡成功",
  "data": {
    "record_no": "DR202609140001",
    "pool_name": "常驻卡池",
    "draw_mode": "single",
    "quota": {
      "single_used": 1,
      "single_limit": 1,
      "ten_used": 0,
      "ten_limit": 1
    },
    "cards": [
      {
        "card_name": "星穹旅人",
        "rarity": "SSR",
        "score": 12
      }
    ]
  }
}
```

### `GET /api/daily-carddraw/today`

用途：

- 查询某个 QQ 今日抽卡结果与剩余次数

查询参数建议：

- `qq_id`
- `pool_key`

### `GET /api/daily-carddraw/history`

用途：

- 分页查询用户历史记录

查询参数建议：

- `qq_id`
- `page`
- `page_size`

## 管理接口

### `POST /api/daily-carddraw/admin/pools`

- 新建卡池

### `PUT /api/daily-carddraw/admin/pools/{pool_id}`

- 修改卡池

### `POST /api/daily-carddraw/admin/cards`

- 新建卡牌

### `PUT /api/daily-carddraw/admin/cards/{card_id}`

- 修改卡牌

### `POST /api/daily-carddraw/admin/pools/{pool_id}/cards`

- 向卡池添加卡牌与权重

### `POST /api/daily-carddraw/admin/reset-quota`

- 重置指定 QQ 在指定日期的抽卡次数

### `GET /api/daily-carddraw/admin/user-records`

- 查看指定 QQ 的抽卡记录

## 插件配置项建议

后续 `_conf_schema.json` 建议至少包含：

- `api_base_url`
- `api_token`
- `default_pool_key`
- `request_timeout_seconds`
- `admin_qq_list`
- `enable_group_usage`
- `enable_private_usage`

其中密钥字段应使用 AstrBot 的 `secret` 配置能力隐藏展示 [$TRAE_REF](https://docs.astrbot.app/dev/star/guides/plugin-config.html)。
