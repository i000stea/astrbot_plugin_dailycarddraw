# 命令与管理接口

## 命令设计原则

第一版命令设计优先保证：

- 好记
- 参数少
- 错误提示清晰
- 兼容群聊和私聊使用

建议命令前缀统一为：

- `抽卡`
- `卡池`

## 用户命令建议

### `抽卡`

默认含义：

- 对默认卡池执行单抽

示例：

```text
抽卡
```

### `抽卡 十连`

默认含义：

- 对默认卡池执行十连

示例：

```text
抽卡 十连
```

### `抽卡 <卡池名>`

含义：

- 对指定卡池执行单抽

示例：

```text
抽卡 常驻池
```

### `抽卡 <卡池名> 十连`

含义：

- 对指定卡池执行十连

示例：

```text
抽卡 常驻池 十连
```

### `抽卡 今日`

含义：

- 查询本人今日抽卡记录与剩余次数

### `抽卡 历史`

含义：

- 查询本人历史记录

### `抽卡 统计`

含义：

- 查询本人累计抽卡统计

## 管理员命令建议

管理员命令建议统一前缀：

- `抽卡管理`

## 卡池管理

### `抽卡管理 卡池列表`

- 查看全部卡池

### `抽卡管理 新建卡池 <名称>`

- 创建卡池基础记录

### `抽卡管理 修改卡池 <卡池ID> ...`

- 修改卡池开关、配额、模式

### `抽卡管理 启用卡池 <卡池ID>`

- 启用卡池

### `抽卡管理 停用卡池 <卡池ID>`

- 停用卡池

## 卡牌管理

### `抽卡管理 新建卡牌 <名称> <稀有度> <分值>`

- 创建卡牌

### `抽卡管理 配置权重 <卡池ID> <卡牌ID> <权重>`

- 将卡牌配置到卡池

## 数据管理

### `抽卡管理 用户记录 <QQ号>`

- 查看指定 QQ 的抽卡记录

### `抽卡管理 重置次数 <QQ号> <卡池ID>`

- 重置指定 QQ 的当日配额

## 权限边界

需要在插件配置中维护管理员 QQ 白名单。

建议规则：

- 用户命令：所有人可用
- 管理命令：仅 `admin_qq_list` 允许
- 后端管理接口：插件访问时追加服务端鉴权 Token

## 后续实现建议

正式开发时，应将“命令解析”和“响应格式化”拆开：

- `controller` 负责识别命令意图
- `message_formatter` 负责统一输出文本模板

这样后续如果要把返回形式改成图片卡片或富文本，不需要重写全部业务流程。
